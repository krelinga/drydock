Drydock figure proofs

The six light/dark pairs in docs/design/frontend/diagrams/, rendered so each variant can actually be looked at. The switch swaps the image file directly rather than leaning on prefers-color-scheme — reviewing a pair means seeing both halves on purpose, not whichever one your OS happens to ask for.

Variant
Each plate sits on the ground its variant is drawn for — white for light, near-black for dark — because a dark diagram checked against a white page looks broken in a way it is not, and a light one checked against black looks fine when it is not.
